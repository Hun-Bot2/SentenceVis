- **런타임:** Vanilla TS + D3 + Vite (D-011 결정). 상태는 `src/state/store.ts`의 단일 저장소 하나에 둔다. V1·V2·V3·범례는 `src/vis/`, 연결은 `src/app/main.ts`가 맡는다.
- **진행 순서 (사용자, 2026-11-16):** ① 끝까지 만들기 → ② 논문 수준으로 다듬기 → ③ 개선. 지금은 ① 단계라 미결정 디자인은 "잠정"으로 표시해 넣었다.

- **도형:** `docs/specs/glyph_registry.json` → `python3 -I scripts/checks/glyphs.py ts src/vis/glyphs.generated.ts`로 생성한다. 손으로 고치지 않는다.
- **개인정보:** `display_ok=false` 문서(115에만 있는 사본)의 문장은 내보내기 단계에서 빠진다. 화면에서는 가림 막대와 "개인정보 보호로 가림"으로 표시된다.
- **작성:** Claude Code(Anthropic). 모든 파일 머리에 AI 작성 표시가 있다.

## 브라우저에서 확인한 것

- **V1:** 1심 단계 → "2심으로" 전환 애니메이션이 동작한다. 점이 2심 위치로 이동하고, 쐐기 선이 형이 늘면 2심 쪽으로 굵어지고 줄면 가늘어진다(예: 2010노1013, 180 → 108개월). 같은 개월은 채운 문서 + `=`, 파기환송은 2심 위의 작은 ⟳로 나온다. 대법원 자리에는 자물쇠·⟳·?·끊긴 점선이 나온다. 집행유예는 합친 글자("실형 → 유예 4년")로, 축 바깥 칸의 머리글은 데이터에서 자동 생성된다.
- **V2:** P01(2005고합52 → 2006노444)을 고르면 사실오인 → 배척, 심신장애 → 배척(막대 끝), 직권 판단 → 파기가 연결되고, "− 성폭력처벌법 제5조"(조문 변화 후보)와 양형 요소 "합의"가 나온다. 노드를 누르면 원문 레인에 근거 문장이 나온다. 같은 유형 요약은 K1 3건, K2 58건이다.
- **고친 버그:** 도형 함수가 `class`를 덮어써 단계 전환이 작동하지 않던 문제. SVG가 영역보다 넓어 오른쪽이 잘리던 문제. 대법원 머리글이 겹치던 문제. 레이아웃이 바뀐 뒤 V2 연결선 좌표가 어긋나던 문제(`ResizeObserver`로 다시 측정).

## 2차 구현 (같은 날)

- **V3 원문 대조 (잠정, 슬라이드 후보 그대로):** 1심·2심 판결문을 나란히 놓았다. 구획 띠의 높이는 구획 길이에 비례하고, 1심은 "본문 | 띠"로 뒤집어 두 띠가 가운데에서 마주 본다. 같은 이름의 구획을 잇는 리본은 구조 대응이며 의미·인과 연결이 아니다. 선택한 근거 문장은 강조하고 그 위치로 스크롤한다. 조문 풀이 패널에는 지식베이스 판본 경고가 붙는다. 가림 문서는 막대로 표시한다.
- **연동:** V1 행 → V2·V3. V1 값 도형 → V3 주문 문구. V2 노드 → V3 2심 근거 문장. V2 조문 칩 → V3 조문 풀이. 확인 예: P01에서 "직권 판단" → 2심 "직권판단" 강조, "형법 53조" → "제53조(작량감경) …" + 2018-01-07 판본 경고.
- **V1:** 축 브러시 확대(두 번 누르면 원래대로; 가로 위치는 실제 개월 유지). 확대 범위 밖의 도형과 글자는 숨긴다. 복수 형은 형마다 축 위에 ∅로 그린다(형별 개월을 내보내기에 추가).
- **한 화면 배치 (잠정):** 왼쪽에 V1(위)·V2(아래), 오른쪽에 V3(위)·범례(아래). 각 패널 안에서 스크롤한다. 1512×900에서 페이지 높이가 화면과 정확히 같다(900px). 1100px 미만에서는 세로로 쌓인다.
- **고친 버그:** V3 띠 뒤집기 선택자(리본 SVG가 첫 자식이라 `:first-child`가 맞지 않음), 확대 시 범위 밖 집행유예 글자가 남는 문제, 머리글 높이 3px 넘침.

## 3차 구현 (같은 날)

- **역선택 V3 → V2:** 2심 원문에서 이유 단서(항소이유·판단·직권·양형 요소) 문구를 점선 밑줄로 표시하고, 누르면 V2의 해당 노드가 선택되며 그 문구가 강조된다. 확인 예: P01의 원문 단서 17개 중 "주장은 이유 없다"를 누르면 V2 "사실오인 → 배척"이 선택된다.
- **같은 유형 목록:** V2 요약의 "같은 항소이유 조합 n건", "같은 결과·직권 n건"을 누를 수 있다. 누르면 사건 목록이 나오고, V1에서 같은 묶음의 행은 강조되며 나머지는 흐려진다(슬라이드의 사건 간 비교). 목록에서 사건을 누르면 그 사건으로 이동한다. 확인 예: P01의 K2 → 58건이 강조되고 179행이 흐려진다. 2006노3300으로 이동해도 목록은 유지된다.
- 상태 저장소에 `group`이 추가됐다. 선택 경로는 여전히 하나다(콜백 → `store.set` → 다시 그림).
- 잠정 표시: V3 단서의 점선 밑줄은 V1의 "대법원 자료 없음" 점선과 뷰는 다르지만 같은 패턴이다. 다듬는 단계에서 확인한다.

## 겹침 수정 (같은 날, 사용자 스크린샷 지적)

- **V1:** 축 바깥 칸 머리글이 눈금 "240"과 겹쳤다. 머리글 띠를 축 위로 분리하고(TOP 64 → 80), 개수는 한 줄에 두 개씩 적는다. 복합 사건번호 행 이름은 "첫 번호 외 n"으로 줄이고 전체 번호는 툴팁에 둔다.
- **V3:** 긴 복합 사건번호가 접혀 법원·날짜·띠를 덮었다. 이제 한 줄로 자르고(외 n건, 전체는 툴팁), 법원·날짜는 다음 줄에 둔다. 띠 이름은 블록 높이가 13px 이상일 때만 쓰고, 낮으면 툴팁에 둔다.
