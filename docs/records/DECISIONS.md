## D-013 · '관계'는 원문 명시 경로로 한정하고, 정확도는 사용자 라벨로 측정

- **상태:** 사용자 결정 2026-11-16 (Claude Code 대화의 선택지 응답).
- **결정:** 판결 사이의 '인과관계·엮인 관계'는 **법원이 판결문에 직접 쓴 항소이유→판단→결론 경로**로만 정의한다. 통계적 인과추정은 하지 않는다(관찰 자료, 비확률 표본, 소표본; AGENTS.md 금지사항과 슬라이드의 "no causal weights" 유지).
- **검증:** 자동 추출(연결·주문·이유 단서)의 정확도는 **사용자가 직접 라벨링한 고정 시드 무작위 표본**으로 측정하고 95% Wilson 구간을 보고한다. 단독 검토자이므로 검토자 간 일치도는 보고할 수 없다.
- **보조 자료:** CCJS 항소심 통계와 양형기준·법령 연혁만 맥락(`contextual`)으로 사용한다. 개별 판결의 원인으로 연결하지 않으며, 뉴스 메타데이터는 최종 인터페이스에서 제외한다.
- **근거·구현:** [VALIDATION §12](../specs/VALIDATION.md#12-자동-추출-파이프라인-스냅샷-2026-11-16), `scripts/align/`, `scripts/annotate/`, `scripts/statistics/context_tables.py`.

## D-014 · 양형 맥락과 조문 풀이는 원문·지식베이스 근거로만, 판본과 방향을 명시

## D-015 · 결측 상태 9종은 우선 그대로 구분

- **상태:** 사용자 결정 2026-11-16 (Claude Code 대화의 선택지 응답).
- **결정:** 값 상태 9종(DATA.md "결측 상태")을 기본 화면에서 묶지 않고 그대로 구분한다. 시각화했을 때 정보량이 넘치면 그때 묶는다.
- **근거 유형:** Primary persona의 질문, 오독 위험 회피, 문헌 근거. 구체적인 문장과 "넘침"의 판단 기준은 미정이다([워크시트 §3](../research/ENCODING_DECISION_WORKSHEET.md#3-값-상태-9종을-화면에서-어떻게-묶을지)의 열린 항목).
- **상태별 표시 (같은 날 추가 결정):** 값 단위 6종은 도형으로 표시한다. 개월 축 위에 자리가 없는 값은 축 바깥의 별도 칸에 둔다. 행·연결·문서 단위 상태는 단위마다 다른 방식으로 표시한다.
- **도형 확정 (같은 날):** observed = 의사봉, derived = 화살촉 점, not_scalar = ∅, absent_in_text = 의사봉(아래 층) + 배경색 테두리를 두른 큰 X(위 층), not_applicable = 가위표 X, not_extracted = 물음표. 사용자가 여러 차례 시안을 비교하고 직접 디자인해 결정했다(과정은 워크시트 §3). 정의는 VISUAL_DESIGN §12에 있다. V1 슬라이드 후보의 ○/● 원은 쓰지 않고, 1심/2심은 도형의 채움이나 선 굵기로 구분한다.
- **재확정 (같은 날):** observed는 천칭(균형 접시), absent_in_text는 천칭 + X 덮개로 바꾼다. 의사봉은 "판결을 내렸다"는 뜻이라 판결 문서 자체(V3 등)를 나타내는 표시로 옮긴다.
- **단위별 방식 (같은 날):** `unresolved`는 사건 단위로 접은 행으로 기본 화면에 보이고, `not_in_corpus`는 대법원 자리로 가는 끊긴 연결선으로, `withheld`는 V3 본문 가림 막대 + 문구로 표시한다.
- **축 바깥 칸 (같은 날):** 개월 축 오른쪽(대법원 자리 앞)에 둔다. 혼합 행은 점선으로 잇고, 복수 형은 형마다 축 위에 ∅를 찍는다.
- **칸 이름 (같은 날):** 머리글은 현재 보이는 행의 종류와 개수로 자동 생성한다(예: 벌금 68 · 무죄 31 · 금고 2 · 추출 실패 9).
- **집행유예 (같은 날):** 점 옆 글자(작은 상태 도형 + "실형 → 유예 2년"처럼 1심·2심을 합친 글자). 개월이 같은 두 천칭은 도형 하나로 합친다.
- **합친 표시 (같은 날):** 합친 천칭은 채운 천칭 + `=`, 합친 글자는 오른쪽 점 옆(넘치면 왼쪽).
- **가까운 행 (같은 날):** 가로 위치는 실제 개월을 지키고, 겹침은 축 확대(브러시)로 푼다. 위치를 인위적으로 옮기지 않는다.
- **대법원 결과 (같은 날, 사용자):** 상고기각 = 자물쇠, 파기환송 = ⟲, 섞임 = `일부 파기` 글자. 파기환송이면 2심 점에도 표시한다.
- **위임 결정 (같은 날):** 사용자가 "나머지 도형은 겹치지 않게 결정해서 최종 문서 제공"이라고 위임했다. Claude가 정한 것: 2심 점의 작은 ⟲, V1 선 패턴(혼합 행 파선 `4 2`, 대법원 연결 실선), 천칭 2심을 굵게, 천칭 + X의 심급 구분 제거, `=`의 크기와 위치, 범례 문구 초안. 근거는 12px 픽셀 유사도 측정이다([V1_ENCODING §6](../specs/V1_ENCODING.md#6-구별-가능성-측정-claude-위임-결정의-근거)). 최종본은 [V1_ENCODING.md](../specs/V1_ENCODING.md)다.
- **미정:** 보고서 근거 문장, "넘침" 판단 기준.

## D-016 · V2 단위와 레인

- **상태:** 사용자 결정 2026-11-16, 진행 중. 기록은 [V2_ENCODING](../specs/V2_ENCODING.md)에 있다.
- **결정:** V2는 V1에서 고른 사건 하나의 경로와 같은 유형의 다른 사건 요약을 보여 준다. 레인은 5개다(항소이유 → 판단 → 법령의 적용(양형 단계) → 양형 요소 → 원문).
- **같은 유형 요약:** K1 항소이유 조합과 K2 결과 + 직권 여부를 둘 다 보여 준다(잠정).
- **빈 양형 요소 레인:** "양형 요소를 찾지 못함" 한 문구. 원인(양형이유 절 없음 / 추출 실패)은 상세 보기에 둔다. 빈 레인의 원인은 연도가 아니라 양형이유 절이 없는 경우라는 점을 확인했다.
- **노드와 선 (같은 날):** 제기자는 글자 배지, 판단은 연결선 끝 모양(인용 화살촉 · 배척 막대 · 판단 안 함 빈 원 · 해당 없음 없음) + 글자로 표시한다.
- **화면을 본 뒤 정하기로 한 것:** 변화 표시(조문 +/− 또는 나란히; 법률 이름 파서는 고침), 출처·검증 선 표시. 원문이 명시한 관계는 현재 데이터에 없다.
- **관찰:** 슬라이드의 "판단 변화"는 파이프라인에 없다. 계산할 수 있는 것은 조문 단위의 변화뿐이다.

## D-011 결정 · 화면 런타임은 Vanilla TS + D3

- **상태:** 사용자 결정 2026-11-16 (D-011 재검토의 결론).
- **선택:** React를 빼고 Vanilla TypeScript + D3로 한다. 빌드는 기존 Vite를 쓴다.
- **사용자가 고른 근거:** 상태 동기화 편의.
- **구현 방침 (Claude):** 상태는 `src/state/`의 단일 저장소 하나에 두고, V1·V2·V3가 그것을 구독한다. 선택이 바뀌는 경로를 하나로 만들어 동기화를 단순하게 한다. D3 그리기 코드는 `src/vis/`에 두며, 경계 검사로 프레임워크 의존을 막는다.
- **측정하지 않은 것:** 다른 런타임과의 성능·번들 비교는 하지 않았다([FRAMEWORK_RUNTIME_REVIEW](../research/FRAMEWORK_RUNTIME_REVIEW.md) §4 계획).
- **V1 선 굵기 재결정 (같은 날, 사용자):** 덤벨 선은 형량이 늘어난 쪽으로 굵어지는 쐐기로 한다(양끝 = 각 심급 개월). 사용자가 1심에서 2심으로 넘기면 선과 점이 애니메이션으로 바뀐다. 이전의 "큰 쪽 기준 일정한 굵기"를 대체한다.
