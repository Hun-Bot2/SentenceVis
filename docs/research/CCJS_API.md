# 형사사법통계 통합조회 로컬 스냅샷

[공공데이터포털 공식 명세](https://www.data.go.kr/data/15163648/openapi.do)는 통계표 ID `table`, 연도 `year`, 행 `row`, 열 `col`과 `serviceKey`를 필수로 명시한다. [제공기관 통계표 카탈로그](https://api2.kicj.re.kr/)에서 조회 대상을 확인한다. 표의 분류·수치 단위·대상 기간·결측 및 실제 응답은 아직 검증하지 않았다.

```sh
python3 scripts/statistics/ccjs_fetch.py
```

Endpoint를 입력하거나 기본값을 사용하고 표 ID, 연도, 행과 열을 입력한다. 발급받은 일반 인증키는 마지막에 숨김 입력한다. 채팅이나 명령행 인자로 키를 보내지 않는다. 인코딩/디코딩 키는 한 번 복원 후 한 번 URL 인코딩한다. 단일 조회만 하며 재시도·자동 연도 확장·페이지 추측은 하지 않는다. 허용 대상은 `apis.data.go.kr` 통합조회 HTTPS 경로이고 리다이렉트는 거부한다. 오류 URL과 응답 본문은 출력하지 않는다.

JSON 원본은 `data/raw/ccjs_statistics/<sha256>.json`, 요청의 비밀 없는 메타데이터는 `requests.jsonl`에 저장한다. 같은 응답 바이트는 중복 보관하지 않으며 개별 조회는 기록한다. JSON 오류 응답도 저장될 수 있으므로 성공·통계 건수·필드 의미는 별도 확인한다. 인증키가 응답 본문에 그대로 포함된 경우 저장을 중단한다. 원본·로그는 기본 Git 제외다. 실 API 호출과 인증은 아직 시험하지 않았다.

이 자료는 집계통계로서 판결문 데이터 및 양형기준의 규범적 권고 구간과 별도다. 개별 사건의 기준 적용 여부를 뒷받침하지 않으며, 분석 범위 2002–2011의 판결 데이터는 바꾸지 않는다. 결과는 `unverified`·`contextual_statistics`·grain `unknown`으로 시작한다. 외부 API 명세는 제공기관 공식 문서에 따르며 코드 작성에 OpenAI Codex를 사용했다.
