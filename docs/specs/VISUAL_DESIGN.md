## 2. 교수님 피드백을 설계 수용 기준으로 번역

1. **채널 선택 이유:** 각 attribute의 semantic type에 맞는 시각적 채널과 대안을 표로 제시한다.
2. **채널 제한:** 한 뷰의 기본 상태에서 *인지적 초점*을 2–3개 정도로 유지하는 것을 **설계 가설**로 삼는다. 이는 논문이 규정한 절대적 채널 수가 아니며 파일럿으로 점검한다.
3. **동일 기호 충돌 최소화:** 동일 화면에서 도형·색·점선이 상충된 뜻을 가지지 않게 한다.
4. **범례:** 전체 시각화의 기본 기호를 쉽게 찾을 수 있는 위치에 항상 표시. 필요한 세부 의미는 뷰별 범례로 확대.
5. **원문 근거:** 기호/연결선만으로 인과를 암시하지 않는다. 실제 판단 구절과 출처 상태를 한 클릭 안에 연결.
6. **과밀도 테스트:** 다수 항소이유·공동피고인·긴 조문·줄바꿈·좁은 화면에서 가독성 확인.

## 4. V1 — Dumbbell, status-separated

- 행 = **사건쌍 내부 피고인**; 공동피고인 미정렬은 숫자 연결선을 그리지 않고 명시적 경고.
- x축 = 징역 개월, 모든 행에 **같은 척도**.
- 1심·2심 위치를 두 점으로 연결. 필요 시 `60 → 42개월` 직접 레이블.
- 집행유예는 독립 상태로 표시. `60→60`이라도 `실형→집행유예`이면 별도 변화로 찾을 수 있어야 한다.
- 대법원 파기·기각은 마진의 절차 상태로 표시; 무조건 ‘세 번째 형량’ 점으로 그리지 않음.
- 인터랙션: 정렬(감소폭/날짜), 유형 필터, 브러시, 행 클릭→V2+V3.
- 변형: ordinal 색상이나 화살표만으로 크기를 판단하게 하지 않음.

## 5. V2 — Path Map, distinguish grounds from judicial action

기존 레인 후보(판결문 문맥과의 일치 여부도 검토 전):

```text
[항소이유/제기] → [법원 판단] → [판단 변화 또는 직권] → [법령의 적용/양형] → [근거 문장]
```

- 당사자가 제기한 `사실오인`, `양형부당` 등은 **주장**; 법원의 `인용/배척`은 **처리 결과**.
- `직권판단`은 별도 유형의 법원 판단이며 당사자에게 인용 처리로 흡수되지 않는다.
- 법률 문구 사이 연결은 `법원 원문 명시 / AI 추출 / 맥락`을 구분한다.
- **기본 상태:** 항소이유 + 결과 + 직권 쟁점 표시. 판단 변화 종류·법령/근거의 상세는 노드 선택 시 강조.
- **클릭:** 1개 경로 하이라이트, 다른 경로 흐림, V3 해당 한국어 문장 열기.
- **교차 필터:** 출처·판단 상태 클릭→V1에서 동일 유형을 갖는 사건 강조; 실제 포함 조건을 공개.
- **링크 의미:** 추출된 경로를 *양형에 미친 정량 기여도* 또는 확정적 인과로 보이지 않게 한다.

## 6. V3 — Evidence-linked reading

- 좌측 1심, 우측 항소심의 문서 섹션을 **본문 순서**로 유지.
- 선택된 판단 경로에 연결되는 문장만 먼저 펼침. 추가 문맥은 명시적 ‘더 보기’로 제공.
- `법령의 적용` 조문과 단순 언급 조문을 시각적으로/텍스트로 구분.
- 문서 구절의 `document_id / section / excerpt / evidence_status`를 확인할 수 있어야 한다.
- 필요한 영어 gloss는 **AI 생성 텍스트**로 명시하고 한국어 원문을 우선한다.
- `원문 블록 클릭`→V2 해당 근거/경로로 역선택.
- 저장되지 않은 법령/누락된 원문은 ‘데이터 없음’으로 표시; 가짜 인용·유사 내용으로 대체 금지.

## 7. 범례(legend) 구조

**전역 범례(항상 접근 가능):**

1. 1심·2심 점 기호 및 징역 개월 수 단위.
2. 형기 감소/유지/증가의 색과 직접 표기.
3. 제기 주체 도형 3종.
4. 원문 명시/추출 관계의 핵심 선 스타일.
5. 검증 전 관계에 대한 텍스트 경고/도움말.

**뷰별 보조 범례:**
- V1 집행유예 전환, 상고심 절차 상태.
- V2 판단 결과 및 변화 기호의 표.
- V3 문서 섹션 역할, 원문·AI gloss 구별.

범례에서 기호를 선택하면 해당 요소를 하이라이트할 수 있다(선택 기능은 보조 기능; 숨기면 해석할 수 없게 만들지 않음). 참고: Dykes et al. [R7].

## 8. 색상·형태·텍스처 제한

- **최초 실험 팔레트 후보:** 감소=청색 계열, 유지=중립 회색, 증가=주황 계열. *최종 확정 아님*, 텍스트·마커와 중복 인코딩.
- 법적 결과의 가치판단(‘감형=선’, ‘증형=악’)을 빨강·초록 의미로 암시하지 않음.
- 법률 섹션의 색은 저채도 배경으로 사용하고 V1의 증감 색과 동일한 채도의 강조표식을 남용하지 않음.
- 텍스처는 복잡한 경로에 도배하지 않음. 필요할 때만 선의 명시/추출 구별에 사용.
- `colorblind` 시뮬레이션, grayscale, 100%/125% 브라우저 줌, 수업 발표 프로젝터 크기를 점검.
- W3C WCAG 2.2: 의미 전달을 색만으로 하지 않으며 필수 그래픽 대비를 점검 ([R8]).

## 11. 설계 판단 전 학습 기록

각 인코딩 행을 [DESIGN_TUTOR.md](../research/DESIGN_TUTOR.md)의 H1–H8 질문과 연결한다. 현재 표의 R#는 일반 연구의 동기이며 해당 도형·팔레트·레이아웃의 우수성을 입증하지 않는다. 세 번째 원문 뷰가 과제의 독립 시각화 컴포넌트 조건을 충족하는지도 교수자 확인 전이다.

## 12. 결측 상태 도형 (확정 2026-11-16)

> **최종본은 [V1_ENCODING.md](V1_ENCODING.md)와 [glyph_registry.json](glyph_registry.json)이다.** 이 절과 최종본이 다르면 최종본을 따른다. 이 절은 결정 이력으로 남겨 둔다.

**상태:** 사용자 결정(D-015; 같은 날 의사봉 → 천칭으로 재결정). 과정은 [워크시트 §3](../research/ENCODING_DECISION_WORKSHEET.md#3-값-상태-9종을-화면에서-어떻게-묶을지)). 값 단위 상태 6종에만 적용한다. 행(`unresolved`)·연결(`not_in_corpus`)·문서(`withheld`) 단위 상태의 표시는 미정이다. 아래 정의는 D3에서 그대로 쓸 수 있는 SVG 경로이며, 좌표계는 `viewBox="0 0 20 20"`이다.

| status | 도형 | 1심(빈 것) / 2심(채운 것) | SVG 정의 |
|---|---|---|---|
| `observed` | 천칭(균형 접시) | 두 접시의 채움 | 기둥: `line 10,3 → 10,17`, 가로대: `line 3,5 → 17,5`, 줄: `M3 5L1.5 10M3 5L4.5 10M17 5L15.5 10M17 5L18.5 10`(굵기 0.9), 접시: `M0.8 10H5.2A2.2 2.2 0 0 1 0.8 10Z`, `M14.8 10H19.2A2.2 2.2 0 0 1 14.8 10Z`(굵기 1.2), 받침: `line 6,17.5 → 14,17.5`. 기둥·가로대·받침 굵기 1.4 |
| `derived` | 화살촉 점 | 점의 채움 | 화살촉: `M3 10H9M6 7L9 10L6 13`, 점: `circle cx13 cy10 r3.5`. 선 굵기 1.4 |
| `not_scalar` | ∅ | 선 굵기 1.4 / 2.4 | `circle cx10 cy10 r6` + `line 4,17 → 16,3` |
| `absent_in_text` | 천칭 + X 덮개 | 아래 천칭 접시의 채움 | 아래 층: `observed`와 같은 천칭. 위 층: `M3 3L17 17M17 3L3 17`을 배경색 굵기 4.4로 먼저 그린 뒤 본문색 굵기 1.8로 덮음 (선 끝 round) |
| `not_applicable` | 가위표 X | 선 굵기 1.4 / 2.6 | `M5 5L15 15M15 5L5 15` (선 끝 round) |
| `not_extracted` | 물음표 | 선 굵기 1.4 / 2.6 | `M6.5 7a3.5 3.5 0 1 1 5 3.2c-1 .5-1.5 1.1-1.5 2.3M10 15.5v1` (선 끝 round) |

**규칙**
- 색은 쓰지 않는다. 색은 다른 속성에 남겨 둔다. 도형은 본문색(`currentColor`)으로 그리고, 덮개 테두리만 배경색을 쓴다.
- `observed`·`derived`는 개월 축 위에 놓는다. `not_scalar`(복수 형)는 형마다 축 위에 ∅를 하나씩 찍는다(사용자 결정 2026-11-16). 징역 개월의 `not_applicable`·`not_extracted`는 **개월 축 오른쪽, 대법원 자리 앞의 별도 칸**에 놓는다(D-015, 2026-11-16). `absent_in_text`는 집행유예 칸에서만 나오므로 집행유예 배치와 함께 정한다(미정). 한쪽만 축에 있는 행은 축 위의 점과 바깥 칸의 표시를 **점선**으로 잇는다. **칸 머리글은 데이터에서 자동 생성한다**(사용자 결정 2026-11-16). 현재 보이는 행에 들어 있는 `reason`별 개수를 다음 이름으로 이어 붙인다: `fine`→벌금, `acquittal`→무죄, `confinement`→금고, `exemption`→면소, `dismissal`→공소기각, `no_parse`→추출 실패. 개수가 0인 종류는 넣지 않는다. `not_applicable`(사실)과 `not_extracted`(모름)가 한 칸에 있으므로, 머리글에 두 종류가 모두 나오는지 확인한다.
- **의사봉은 '판결 문서 자체'를 나타내는 표시로 쓴다(V3 등, 사용자 결정 2026-11-16).** 의사봉은 "판결을 내렸다"는 뜻이라 값 상태에서는 빼고 판결 단위로 옮겼다. 정의는 직전 판(의사봉: 머리 `rect x5 y3 w10 h5 rx1`·손잡이 `line 10,8 → 10,16`, 둘 다 `rotate(-35 10 10)`, 받침 `line 3,18 → 11,18`)을 유지한다. 문서 단위 상태 `withheld`를 이 의사봉과 어떻게 결합할지는 미정이다.
- V1 슬라이드 후보의 ○(1심)/●(2심) 원은 이 도형들로 대체된다. 심급 구분은 위 표의 채움이나 선 굵기로 한다.
- **다른 칸에 거는 제약:** V2의 `배척`에는 X를 쓰지 않는다. V2 판단 변화의 `?`(불명확)는 `not_extracted`의 물음표와 뜻이 겹치지 않게 다시 정한다. 집행유예 표시로 쓰던 점선 고리는 이 6종과 겹치지 않는지 따로 확인한다.
- **집행유예 (사용자 결정 2026-11-16):** 점 옆에 글자 하나로 표시한다. 1심과 2심을 합쳐 "실형 → 유예 2년"으로 쓰고, 같으면 "유예 2년 유지"로 쓴다. 글자 앞에는 상태 도형을 작게 붙인다(천칭 = 유예 있음, 천칭 + X = 실형(유예 조항 없음), X = 해당 없음, ? = 추출 실패). 기간은 연 단위 글자로 쓴다(12·24·36·48개월 → 1–4년). 개월이 같은 두 천칭은 도형 하나로 합친다. 합친 글자는 오른쪽 점 바로 옆에 두고, 축 끝을 넘으면 왼쪽에 둔다. 개월이 같아 합친 천칭은 채운 천칭 + `=` 표시로 그린다(사용자 결정 2026-11-16). 개월이 다르지만 도형이 겹치는 경우(2–4개월 차이 5행)에도 **가로 위치는 실제 개월을 지킨다.** 기본 화면에서는 겹친 채로 두고, 개월 축 브러시로 확대하면 풀린다(0–60개월 범위에서 1개월 8px; 사용자 결정 2026-11-16). 위치를 옮기는 지터(jitter)는 쓰지 않는다.
- **단위별 상태 (사용자 결정 2026-11-16):**
  - `unresolved`(행): V1에서 사건쌍 단위로 접은 행. 사건번호 · 공동피고인 수 · "정렬 전" 문구를 쓰고, 개월 값은 그리지 않는다. 기본 화면에 보인다.
  - `not_in_corpus`(연결): V1 행 끝에서 대법원 자리로 가는 선이 끊기고, 나머지는 점선. 끊긴 지점의 표시는 가위표와 닮지 않게 한다.
  - `withheld`(문서): V3 판결 문서(의사봉 표시)의 본문 자리를 가림 막대로 덮고 "개인정보 보호로 가림" 문구를 붙인다.
- **미확인:** 실제 구현 화면의 9px 크기에서 `absent_in_text`와 `not_applicable`이 구별되는지는 아직 확인하지 않았다. 미리보기: `artifacts/design/status_glyphs.svg`(로컬, 공개 전 검토 대상).
