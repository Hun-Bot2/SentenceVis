- **상태:** 확정본(2026-11-16 재확정: 조항 값 = 줄 그은 문서, 무거움 = 덤벨 선 굵기, 파기환송 = ⟳ 반대 방향, 천칭 제외). 이전의 "제안 후보"를 대체한다. 결정 과정은 [인코딩 워크시트 §3](../research/ENCODING_DECISION_WORKSHEET.md#3-값-상태-9종을-화면에서-어떻게-묶을지), 결정 기록은 [D-015](../records/DECISIONS.md)에 있다.
- **결정한 사람:** 표마다 `사용자` 또는 `Claude(위임)`으로 적었다. `Claude(위임)`은 사용자가 2026-11-16에 "나머지 도형은 겹치지 않게 결정해서 최종 문서 제공"이라고 위임한 항목이다. 그 근거는 §6의 측정이다. 사용자가 언제든 바꿀 수 있다.
- **도형 정의의 단일 출처:** [glyph_registry.json](glyph_registry.json). 화면 구현, 범례, 측정 모두 이 파일에서 생성한다(`scripts/checks/glyphs.py`).
- **작성:** Claude Code(Anthropic). 사용자의 결정을 기록했고, 위임받은 항목만 Claude가 정했다.

## 1. V1 가로 배치 (왼쪽 → 오른쪽)

```text
[행 이름] [개월 축: 0 ──────── 최대] [축 바깥 칸] [대법원 자리]
```

| 요소 | 규칙 | 결정 |
|---|---|---|
| 개월 축 | 모든 행이 같은 척도. 가로 위치 = 실제 징역 개월. 위치를 옮기는 지터는 쓰지 않음 | 사용자 |
| 축 바깥 칸 | 축 오른쪽, 대법원 자리 앞. 징역 개월의 `not_applicable`·`not_extracted` | 사용자 |
| 축 바깥 칸 머리글 | 보이는 행에 들어 있는 종류와 개수로 자동 생성. 예: `벌금 68 · 무죄 31 · 금고 2 · 추출 실패 9`(0은 생략) | 사용자 |
| 대법원 자리 | 오른쪽 여백. 행 끝에서 실선이 이어진다 | 사용자(위치) · Claude(위임, 실선) |
| 공동피고인 정렬 전 | 사건 단위로 접은 행 `▸ 사건번호 · 공동피고인 n명 · 정렬 전`. 개월 값은 그리지 않음. 기본 화면에 보임 | 사용자 |

## 2. 값 상태 도형

1심은 빈 모양이나 가는 선, 2심은 채운 모양이나 굵은 선이다. 그림은 `artifacts/design/legend_draft.svg`(로컬)에 있다.

| status | 도형 | 1심 / 2심 구분 | 놓이는 곳 | 결정 |
|---|---|---|---|---|
| `observed` | 줄 그은 문서(접힌 모서리 + 줄 3개) | 2심: 채운 문서, 줄은 배경색 | 개월 축 | 사용자 |
| (개월이 같은 1·2심) | 채운 문서 + `=` | — (합친 표시) | 개월 축 | 사용자 · Claude(위임, `=` 크기 3·위치) |
| `derived` | 화살촉 점 | 점 채움 | 개월 축 | 사용자 |
| `not_scalar` | ∅, 형마다 하나씩 | 선 굵기 | 개월 축(형마다 실제 위치) | 사용자 |
| `absent_in_text` | 문서 + X 덮개(굵기 2.4, 테두리 5) | **구분 없음**: 집행유예 글자의 "1심 → 2심" 순서가 심급을 알려 줌 | 집행유예 글자 앞(작게) | 사용자(도형) · Claude(위임, 심급 구분 제거·X 굵기) |
| `not_applicable` | X | 선 굵기 | 축 바깥 칸 / 집행유예 글자 앞 | 사용자 |
| `not_extracted` | ? | 선 굵기 | 축 바깥 칸 / 집행유예 글자 앞 / 대법원 자리 | 사용자 |

## 3. 대법원 결과

| 결과 | 표시 | 결정 |
|---|---|---|
| 상고기각 (2심 확정) | 자물쇠 | 사용자 |
| 파기환송 (2심은 최종 형이 아님) | ⟳(회전 방향 반전, 사용자 2026-11-16), 그리고 **2심 점 바로 위 가운데에 작은 ⟳**(크기 0.55배) | 사용자(⟳ 방향, 2심 점에도 표시, 위 가운데) · Claude(위임, 크기) |
| 기각과 파기가 섞임 | 글자 `일부 파기`. 2심 점에도 작은 ⟳ | 사용자(글자) · Claude(위임, 섞임도 2심 점에 표시) |
| 추출 실패 | ? | 사용자(D-015 도형 재사용) |
| 자료 없음 (`not_in_corpus`) | 끊긴 연결선(실선 → 틈 → 점선) | 사용자 |

`일부 파기`인데 2심 점에도 표시하는 이유는 이렇다. 단독 피고인 행에서 섞임은 검사·피고인 상고의 결과가 갈린 경우다. 그런데 파기된 부분이 그 피고인의 형에 닿는지는 자동으로 판정할 수 없다. 그래서 "최종 아님일 수 있음" 쪽으로 표시한다.

**행 높이:** 2심 점 위에 ⟳가 올라가므로 V1 행 간격은 약 20px 이상이어야 한다(도형 12px + ⟳ 약 7px).

**천칭의 이력:** 조항 값(`observed`)은 접힌 문서 → 의사봉 → 천칭 → 줄 그은 문서 순서로 바뀌었다. 천칭이 빠진 이유는 사용자가 "형량에 대해서 무거움을 표현하는 게 있어야 하고, 조항 값은 따로 마크를 하나 더 쓰는 게 좋을 듯"이라고 정했기 때문이다. 무거움은 덤벨 선 굵기로 옮겼다. 천칭의 다른 용도는 미정이다.

**검토 후 채택하지 않은 안 (사용자, 2026-11-16):** 1심·2심을 천칭의 두 접시에 두고, 유지·변경된 쪽이 내려가게 하는 "기울어진 천칭". 함께 검토한 관찰은 세 가지였다. ① 형의 무게를 다루는 화면이라, 내려간 접시가 "더 무거운 형"으로 오독될 수 있다(예: 감형인데 2심 쪽이 내려감). ② 덤벨 방향·집행유예 글자와 정보가 겹친다. ③ 12px에서 15° 기울여도 접시 높이 차이가 약 2px다.

## 4. 선

| 선 | 모양 | 뜻 | 결정 |
|---|---|---|---|
| 덤벨 선 | 실선 쐐기. **양끝 굵기 = 그 심급의 개월**: `1 + 5 × 개월 / 240` px (1–6px). 형이 늘면 2심 쪽으로 굵어지고, 줄면 얇아진다 | 1심 → 2심 징역 개월 변화와 **형량의 무거움**(징역 개월만; 집행유예·형종과 합치지 않음). 개월이 같아 선이 없는 행에는 무거움을 따로 표시하지 않음 | 사용자(2026-11-16 재결정: 큰 쪽 기준의 일정한 굵기 W2 → 늘어난 쪽으로 굵어지는 쐐기) · Claude(위임, 1–6px 범위) |
| 혼합 행 연결 | 파선 `4 2` | 축 위 점 ↔ 축 바깥 칸 표시 (징역 → 무죄 등). 길이는 의미 없음 | 사용자(점선으로 이음) · Claude(위임, 패턴) |
| 대법원 연결 | 실선 | 행 → 대법원 자리 | Claude(위임) |
| 대법원 자료 없음 | 실선 → 틈 → 점 `1 3` | N2 | 사용자 |

V1 안에서 끊어진 선은 두 가지뿐이다. 파선 `4 2`(혼합 행)와 점 `1 3`(자료 없음)이며 패턴을 다르게 했다. 슬라이드 후보였던 "집행유예 점선 고리"는 집행유예를 글자로 표시하기로 하면서 **쓰지 않는다**.

### 심급 전환 애니메이션 (사용자 요구, 2026-11-16)

- V1에는 "1심 → 2심" 단계 전환이 있다. 1심 단계에서는 1심 값만 보이고, 선은 1심 개월 굵기의 짧은 표시다.
- 사용자가 다음 재판(2심)으로 넘기면 점이 2심 위치로 이동하고, 선이 쐐기로 늘어나면서 굵기가 2심 개월로 바뀐다. 형이 늘면 두꺼워지고 줄면 얇아진다.
- 전환 중에도 가로 위치는 실제 개월 사이를 잇는 보간값만 쓴다. 전환이 끝나면 정적인 쐐기 덤벨과 같은 그림이 된다.
- 접근성: 움직임을 줄이도록 설정한 사용자(`prefers-reduced-motion`)에게는 애니메이션 없이 바로 최종 상태를 보인다(Claude 위임).

## 6. 구별 가능성 측정 (Claude 위임 결정의 근거)

- **방법:** 등록표의 모든 도형 변형 15개를 화면과 같은 배율(도형 20단위 = 12px)로 래스터화했다. 캔버스는 도형 칸 바깥(-3–29단위)까지 덮어서, 칸 밖에 그리는 표시(`=` 등)도 실제 크기로 담았다(브라우저 렌더링, 회색조 잉크). 두 도형 사이의 유사도는 `Σmin(잉크) / Σmax(잉크)`이고, 1이면 같은 그림이다. 재현은 `python3 -I scripts/checks/glyphs.py check-html <파일>`로 페이지를 만든 뒤 브라우저에서 열면 `window.RESULT`에 결과가 나온다.
- **기준 (프로젝트가 정한 값, 문헌 수치 아님):** 서로 다른 상태끼리 0.6 미만, 같은 기호의 1심 ↔ 2심 0.85 미만.

| 단계 | 기준을 넘은 쌍 | 조치 |
|---|---|---|
| 천칭안, 처음 | 천칭 2심 ↔ 합친 천칭 0.957, 천칭 + X 1심 ↔ 2심 0.956, 천칭 1심 ↔ 2심 0.932 | 접시가 12px에서 1–2px라 채움이 거의 보이지 않았다. 굵기를 보정하고, X 덮개의 심급 구분을 없애고, `=`를 키웠다 |
| 문서안, 처음 | 문서 2심 ↔ 합친 문서 0.866, 문서 1심 ↔ 문서 + X 0.631 | X 덮개를 굵기 2.4·테두리 5로, `=`를 굵기 3·길이 7로 |
| 측정 방법 정정 | — | 틀을 넓히면서 도형이 실제보다 작게 그려진 오류를 발견했다. 배율을 고정하고 캔버스만 넓히도록 고쳤다 |
| **문서안, 최종** | **없음.** 상태 간 최대 0.529(문서 2심 ↔ ∅ 2심), 심급 간 최대 0.818(문서 2심 ↔ 합친 문서) | — |

- **한계:** 픽셀 유사도는 사람의 구별을 대신하지 않는다. 실제 V1 화면에서 사람이 확인해야 한다(파일럿 또는 사용자 확인). 덤벨 선 굵기(무거움)와 도형 선 굵기(심급)는 같은 채널을 두 뜻으로 쓰므로, 범례에서 둘을 따로 설명한다.

## 7. 범례 문구 (Claude 위임 초안)

화면 어딘가에 항상 보이는 전체 범례의 문구다. 도형 옆에 이 글자를 그대로 쓴다.

| 범례 항목 | 문구 |
|---|---|
| 심급 | 도형: 빈 모양·가는 선 = 1심 · 채운 모양·굵은 선 = 2심 |
| 선 굵기 | 1심–2심을 잇는 선이 굵을수록 징역이 긺(두 값 중 큰 쪽 기준) |
| 줄 그은 문서 | 판결 주문에 적힌 징역 |
| 문서 + `=` | 1심과 2심의 징역이 같음 |
| 화살촉 점 | 항소기각으로 1심 형이 그대로 유지됨(유도한 값) |
| ∅ | 형이 여러 개라 하나의 숫자로 보이지 않음 |
| 문서 + X | 주문에 해당 조항이 없음(예: 집행유예 없음 = 실형) |
| X | 이 형 종류에는 해당 없음(벌금·무죄 등) |
| ? | 원문은 있으나 자동 추출 실패 |
| 자물쇠 | 대법원 상고기각: 2심 판결 확정 |
| ⟳ | 대법원 파기환송: 2심 형은 최종 형이 아님 |
| `일부 파기` | 대법원이 일부만 파기함 |
| 끊긴 선 | 대법원 판결이 이 자료에 없음(상고가 없었다는 뜻이 아님) |
| 파선 | 징역에서 징역이 아닌 형(무죄·벌금 등)으로 바뀜 |
| ▸ 정렬 전 | 공동피고인 대응을 아직 확인하지 않음 |

## 8. 다른 뷰에 거는 제약 (아직 결정 아님)

- V2의 `배척`에는 X를 쓰지 않는다.
- V2 판단 변화의 `?`(불명확)는 V1의 `?`(추출 실패)와 뜻이 다르므로 다른 기호를 써야 한다.
- V2의 출처 근거 선(원문 명시 실선 / 추출 파선 / 맥락 점선)은 V1의 파선 `4 2`·점 `1 3`과 뜻이 다르다. 전체 범례에서 뷰별로 구분해 적는다.
