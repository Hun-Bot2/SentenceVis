## 0. 기준 태스크와 분해

사용자 질문 **"형량이 왜 달라졌는가?"**를 세 하위 질문으로 나눈다. 모든 정보와 상호작용은 이 셋 중 하나에 답할 때만 화면에 올린다.

| 하위 질문 | 태스크 | 뷰 | 답이 되는 최소 정보 |
|---|---|---|---|
| Q1 무엇이 얼마나 달라졌나 | T1 Locate | V1 | 1심·2심 형(개월, 집행유예), 변화 방향, 확정 여부 |
| Q2 누가 무엇을 다퉜고 법원은 어떻게 처리했나 | T2 Compare | V2 | 쟁점별 제기자, 처리(인용/배척/판단 생략), 직권 판단, 파기 여부 |
| Q3 그 처리가 판결문 어디에 적혀 있나 | T3 Trace | V3 | 해당 문장, 구획, 출처 상태 |

"왜"에 대한 답은 **법원이 적은 처리와 그 문장까지**다. 처리와 형 변화 사이의 인과나 기여도는 표시하지 않는다(D-013).

## 5. 뷰 연결 규칙 (Coordinated Interaction)

1. **선택은 하나.** 한 번에 강조되는 경로는 하나다. 새 선택은 이전 선택을 대체한다.
2. **V1은 움직이지 않는다.** 선택 때문에 V1 행 순서, 확대, 스크롤이 바뀌지 않는다. 사용자의 위치 기준점이다.
3. **숨기지 않고 흐린다.** 선택 밖의 쟁점과 행은 흐리게만 하고 지우지 않는다. 개수도 바뀌지 않는다.
4. **움직임은 짧게.** 선택 강조는 즉시 반영한다. 애니메이션은 1심→2심 단계 전환에만 쓰고, 움직임 줄이기 설정을 따른다.
5. **경로 표시 한 줄.** 상단에 "사건 2006노444 › 사실오인 › '주장은 이유 없다'" 형식으로 현재 상태를 보이고, 각 마디를 눌러 그 단계로 돌아간다.
6. **V3 스크롤은 요청한 문장으로만** 이동한다. 사건만 고른 S1에서는 주문 구획까지만 간다.

## 6. 축소해도 지켜야 할 법적 의미 (Critical Information)

정보를 묶거나 접어도 다음 구분은 합치지 않는다.

| 구분 | 값 | 화면 규칙 |
|---|---|---|
| 처리 | 인용 / 배척 / **판단 생략**(법원이 판단하지 않았다고 적음) / **판단 문구 미추출**(우리 추출 실패) | 서로 다른 선 끝 모양. 판단 생략과 미추출은 같은 기호를 쓰지 않는다. 미추출은 결측 상태 `not_extracted` 기호를 쓴다 |
| 직권 판단 | 당사자 주장과 별개 | 쟁점 노드에 흡수하지 않는다. 별도 노드로 둔다 |
| 파기 | 원심판결을 깨뜨린 결과 | 쟁점의 "인용"과 같은 표시를 쓰지 않는다. 파기의 근거가 직권인지 인용인지는 원문 문장으로만 연결한다 |
| 실제 결과 | 2심 주문의 형 | 쟁점 처리에서 추론하지 않는다. V1의 주문 값만 쓴다 |
| 혼재 | 한 쟁점에 서로 다른 처리 | 다수결로 하나를 고르지 않는다. 처리별 개수를 보인다 |
| 대상 미상 판단 | 쟁점에 붙지 않은 판단 문구 | 버리지 않는다. 개수를 보인다 |
| 추출 상태 | 규칙 추출, 검토 전 | 경로 표시 옆에 항상 표시한다. 라벨링을 마치면 검토한 것과 검토 전인 것을 구분한다 |

## 7. 현재 구현과의 차이 (제안 승인 시 고칠 것)

- V2는 쟁점별로 묶지 않고 단서를 하나씩 그린다(`MAX_DISP 8`). → 쟁점 묶음과 S2 펼침이 필요하다.
- "판단 안 함"이 법원의 판단 생략만 뜻하는지, 미추출과 섞여 있는지 화면에서 구분되지 않는다. → §6 규칙.
- 대상 미상 판단(49%)과 혼재 쟁점을 따로 보여 주지 않는다.
- 경로 표시, Esc로 한 단계 올라가기, V1 정렬 전 행 펼치기(S1p)가 없다.
- 묶음(G) 상태에서 V1의 나머지 행을 흐리게 하는 것은 이미 있다.

## 8. 사용자가 정할 것

1. L0–L3에 정보를 배정한 것(§2 표)에 동의하는가? 특히 법령의 적용·양형 요소를 L2로 내리는 것.
2. 복잡 사건 경계(이유 단서 25개)와 노드 상한(8개).
3. 판단 생략과 미추출을 어떤 기호로 나눌 것인가.
4. 경로 표시(빵부스러기)와 Esc 되돌리기를 도입할 것인가.
5. "피고인 선택" 상태: 지금 자료로는 정렬 전 공동피고인을 펼치는 것만 가능하다. 이것으로 충분한가?
